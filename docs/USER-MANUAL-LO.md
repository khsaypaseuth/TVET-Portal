# ຄູ່ມືຜູ້ໃຊ້ TVED (ພາສາລາວ)

## 1. ເຂົ້າສູ່ລະບົບ
1. ເປີດໜ້າ Sign In
2. ໃສ່ **ລະຫັດພະນັກງານ** ຫຼື **ອີເມວ** ແລະ ລະຫັດຜ່ານ
3. ກົດ «ເຂົ້າສູ່ລະບົບ»

ບັນຊີຖືກສ້າງໂດຍ Super Admin ເທົ່ານັ້ນ.

## 2. ບັນທຶກກິດຈະກຳ
1. ເລືອກເມນູ **ກິດຈະກຳ** → **ກິດຈະກຳໃໝ່**
2. ເລືອກປະເພດ, ປ້ອນຫົວຂໍ້ພາສາລາວ, ວັນທີ/ເວລາ
3. ກົດ **ບັນທຶກ** (ສະຖານະ: ຮ່າງ)
4. ເປີດລາຍການ ແລະ ກົດ **ສົ່ງ** ເພື່ອໃຫ້ຫົວໜ້າອະນຸມັດ

## 3. ການອະນຸມັດ (ຫົວໜ້າ/ຜູ້ຄຸ້ມ)
1. ເປີດ **ການອະນຸມັດ**
2. ກວດລາຍການທີ່ສົ່ງມາ → **ອະນຸມັດ** ຫຼື **ປະຕິເສດ** (ພ້ອມເຫດຜົນ)

## 4. ລາຍງານ
1. ເປີດ **ລາຍງານ**
2. ເລືອກປະເພດ ແລະ ໄລຍະວັນທີ
3. ສົ່ງອອກ **Excel** ຫຼື **PDF**

## 5. ປ່ຽນພາສາ
ໃຊ້ປຸ່ມປ່ຽນພາສາຢູ່ມຸມໜ້າຈໍ (ລາວ / English)
